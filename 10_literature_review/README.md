# Literature Review

This directory contains the literature research and related work analysis for the project.

## Methodology

To find relevant publications, comprehensive literature searches were conducted across several major academic databases:

- Google Scholar
- IEEE Xplore
- ACM Digital Library
- Springer
- Elsevier

From these searches, **10 key papers** were selected that are highly relevant to our specific research focus. A [`refs.bib`](refs.bib) file is included, containing the bibliographic information for these publications.

## Contents

The related work is stored in [`review.md`](review.md). The relevant information extracted from the selected papers is documented here. Additionally, each of the 10 publications is summarized in a tabular format to provide a quick and clear overview of the most important information, methodologies, and findings.
