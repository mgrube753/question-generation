### Question Generation

Frage: Veranschaulichen Sie anhand eines konkreten Anwendungsfalls das Zusammenspiel von Codierung, Transport und Decodierung bei der Übertragung einer Bitfolge vom Sender zum Empfänger.

### Answer Generation + Union of all

Frage: Veranschaulichen Sie anhand eines konkreten Anwendungsfalls das Zusammenspiel von Codierung, Transport und Decodierung bei der Übertragung einer Bitfolge vom Sender zum Empfänger.

Antwort: Ein Computer A möchte die Bitfolge "1100" an Computer B über ein Ethernet-Kabel senden. Im ersten Schritt erfolgt die Codierung: Der Sender wandelt die logischen Werte mittels Manchester-Codierung in physikalische Größen um. Dabei wird eine logische "1" durch einen Spannungswechsel von niedrig nach hoch in der Bitmitte dargestellt, eine logische "0" durch einen Wechsel von hoch nach niedrig. Die Bitfolge "1100" wird so in eine definierte Folge von Spannungswechseln transformiert. Im zweiten Schritt findet der Transport statt: Die elektrischen Spannungssignale werden mediengebunden über das Kupferkabel von Computer A zu Computer B übertragen. Das Kabel dient als physikalisches Transportmedium für die elektrischen Signale. Im dritten Schritt erfolgt die Decodierung: Computer B tastet das ankommende Signal zu festgelegten Zeitpunkten in der Bitmitte ab. Anhand der Detektionsbereiche wird ermittelt, ob die Spannung gerade steigt oder fällt. Ein steigender Spannungswechsel wird als logische "1" interpretiert, ein fallender als logische "0". Der Empfänger rekonstruiert so die ursprüngliche Bitfolge "1100". Das Zusammenspiel dieser drei Kernaufgaben ermöglicht die zuverlässige Übertragung logischer Informationen über physikalische Medien. (Richtig)

Bereitstellung einer physikalischen Konzeption für Codierung, Transport und

3 Kernaufgaben

Codierung:

Abbildung logischer Werteauf physikalische Größen.
Bsp: NRZ, Manchester.

Transport:

Übertragung physikalischer Größen
von einem Ort zum anderen.
Medien-gebunden. Bsp: Telefonkabel.
Medien-frei.
Bsp: Lichtsignal, Funk.

Decodierung:

Rückinterpretation physikalischer Größen als logische Werte.
Bsp: Abtastung, Detektionsbereiche.
