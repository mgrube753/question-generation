# Project Archives

This directory includes archived versions with deprecated experiment runs, and old prompt versions from the early stages of our research project.

It allows us to ensure complete traceability of our decisions over time, and to maintain a clear record of the stepwise changes in our methodology.

## Directory Structure

The archives are organized chronologically, capturing distinct phases of the project. For each archive, a `notes.md` file provides context on why the specific version was archived.

### Experiment Archives

These directories contain the `20_experiments` folder each at specific points in time. They include old source files, generated questions that did not meet our final quality standards or used outdated rubrics.

* **[`10_archive090126/`](10_archive090126/)**
  * Snapshot from January 9, 2026.
  * Contains the earliest structured generation runs for Exp 1 and Exp 2.
* **[`20_archive170126/`](20_archive170126/)**
  * Snapshot from January 17, 2026.
  * Shows the state of the project which had prompt-based refinements after the initial runs, but these questions were still not suitable for the blind test.
* **[`30_archive210226/`](30_archive210226/)**
  * Snapshot from February 21, 2026.
  * Prompt-based changes were done for this version, the rater rubric and guidelines were updated
  * The workshops were conducted, and the feedback from the workshops showed that the questions need to be tweaked again, and a new generation run is necessary (regarding learning objectives and Bloom's taxonomy descriptions).
